# MobileLabsRN 2025

This repository contains laboratory work projects developed using React Native.

Branches:
* **Lab 1:** `main`
* **Lab 3:** `lab-3`
* **Lab 5:** `lab-5`

## 🏁 Getting Started

Follow these steps to run the project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Vitalik-Sadok/MobileLabsRN2025.git
    cd MobileLabsRN2025
    ```

2.  **Install dependencies:**
    Using `npm`:
    ```bash
    npm install
    ```

3.  **Start the Expo development server:**
    ```bash
    npx expo start
    ```
    This command will start the Metro Bundler and display a QR code and options for running the app.

4.  **Open the app:**
    * **On a physical device:**
        * **Android:** Open the Expo Go app and scan the QR code shown in the terminal.
        * **iOS:** Open the standard Camera app and scan the QR code.
    * **On an emulator/simulator:**
        * Press `a` in the terminal to open the app on an Android emulator.
        * Press `i` in the terminal to open the app on an iOS simulator.
